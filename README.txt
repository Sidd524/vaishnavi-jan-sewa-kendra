VAISHNAVI JAN SEWA KENDRA - STARTER PWA

FILES
- index.html: app interface and local-first data storage
- manifest.json + sw.js + icon.svg: installable PWA support
- Code.gs: optional Google Apps Script endpoint starter

RUN
1. Upload all files to a GitHub repository.
2. Enable GitHub Pages (Settings > Pages > Deploy from branch > main / root).
3. Open the published HTTPS link on Android Chrome. Menu > Add to Home screen / Install app.

IMPORTANT DATA NOTE
This starter currently saves records in the browser's localStorage on that device. It does NOT yet sync records to Google Drive/Sheets. The Code.gs file is a starter backend only; the front-end sync integration and authentication still need to be completed before using it for real customer records.

Do not store Aadhaar numbers, bank details, passwords, OTPs, or sensitive identity documents in this starter app. Use authorized portals for official services. Keep backups secure.
